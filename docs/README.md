# Official Library folder

Put law files here (PDF, DOCX, TXT). On startup the backend indexes every new file
into the **Official Library**. Files that were already indexed (same content) are skipped.

## Suggested starter set

**Azerbaijan** (download from https://e-qanun.az, use the latest consolidated version):

1. Law on Information, Informatization and Protection of Information (No. 460-IQ, incl. 2026 amendments)
2. Law on Personal Data (2010)
3. Criminal Code: only the chapter on crimes against computer information (copy that chapter into a TXT/DOCX;
   the full code is huge and would use up the free Gemini quota)
4. Presidential Decree No. 1315 (2021) on the security of critical information infrastructure
5. Cabinet of Ministers Decisions No. 229 and No. 230 (2023)
6. Information Security and Cybersecurity Strategy 2023–2027

**International** (English):

7. GDPR (Regulation (EU) 2016/679)
8. Budapest Convention on Cybercrime
9. Optional: NIST Cybersecurity Framework 2.0, NIS2 Directive

Tips:
- Text-based PDFs work best. Scanned PDFs (images) contain no text and will fail.
- Clear file names become document titles, e.g. `Ferdi melumatlar haqqinda Qanun.pdf`.
